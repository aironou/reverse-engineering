# reverse engineering

this project provides containerized environments and makefile workflows
for reverse engineering.

## host dependencies

- [gnu make](https://www.gnu.org/software/make/)
- [posix shell](https://www.opengroup.org/austin/)
- [docker engine](https://docs.docker.com/engine/)
- [docker compose](https://docs.docker.com/compose/)
- [gnu coreutils](https://www.gnu.org/software/coreutils/)
- [gnu findutils](https://www.gnu.org/software/findutils/)
- [gnu parallel](https://www.gnu.org/software/parallel/)
- [gnu sed](https://www.gnu.org/software/sed/)
- [util-linux](https://github.com/util-linux/util-linux)
- [ncurses](https://invisible-island.net/ncurses/)
- [xorg](https://www.x.org/)
- [linux kvm](https://docs.kernel.org/virt/kvm/index.html)
- [linux drm](https://docs.kernel.org/gpu/)
